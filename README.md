# 腦中風 PAC 衛教 APP：上線說明（給資訊室）

這是一個純靜態的網頁 APP（PWA）。沒有後端、沒有資料庫、不連任何外部服務，不收集個資。
使用者的字級、語言與清單勾選只存在自己手機的瀏覽器（localStorage）。

## 資料夾內容

| 檔案 | 用途 |
|---|---|
| `index.html` | APP 本體（五種語言、圖解、程式都在這一個檔） |
| `manifest.webmanifest` | APP 名稱、圖示、顏色，讓手機可以「加入主畫面」 |
| `sw.js` | 離線快取，第一次開過之後沒網路也能看 |
| `icons/` | APP 圖示（目前是暫用圖，可換成院徽） |

## 上線步驟

1. 把整個資料夾放到院內網站的一個路徑下，例如 `https://醫院網域/pac/`。
2. 必須是 **HTTPS**。沒有 HTTPS 就不能加入主畫面，也不能離線使用。
3. 確認伺服器回傳的檔案類型：`.webmanifest` 為 `application/manifest+json`（或 `application/json`），`.js` 為 `text/javascript`。
4. `sw.js` 請設定不要被長時間快取（例如 `Cache-Control: no-cache`），否則更新會延遲。
5. 用手機開網址測試，再把網址做成 QR code。

## 使用者怎麼安裝

- Android（Chrome）：開啟網址 → 選單 →「加到主畫面」或「安裝應用程式」。
- iPhone（Safari）：開啟網址 → 分享按鈕 →「加入主畫面」。
- 不安裝也可以直接用瀏覽器看。

## 之後怎麼更新內容

1. 換上新的 `index.html`。
2. 把 `sw.js` 第 2 行的 `VERSION` 改成新的字串（例如日期）。
3. 使用者下次有網路時開啟就會拿到新版。

## 上線前要完成的事

- 中文衛教內容與圖解尚未經醫療團隊審閱。
- 英文、印尼文、越南文、泰文是翻譯草稿，尚未經母語醫護人員審閱。
- 圖示與名稱可依院方識別調整。
- 畫面上的「試用版」字樣在正式上線時移除。
